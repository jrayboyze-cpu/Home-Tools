Connect your Google Drive to sync recipes and back up your meal history across devices. This needs a one-time OAuth Client ID (only the household admin does this — family members just use your share link).

How do I get a Client ID? (5 min, one time)
  1. Go to console.cloud.google.com and create a project.
  2. Enable the Google Drive API (APIs & Services → Library).
  3. Configure the OAuth consent screen (External, add your family's emails as test users).
  4. Create Credentials → OAuth Client ID → Web application.
  5. Add this page's origin (shown below) to "Authorized JavaScript origins".
  6. Copy the Client ID and paste it here.
